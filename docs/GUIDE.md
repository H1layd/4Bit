# 4bit — руководство

## Установка
1. Rust: https://rustup.rs (одна команда в терминале).
2. Движок: `git clone <репозиторий 4bit>` и в его папке `cargo build --release` (первая сборка — несколько минут).
3. Окно 4bit: `target/release/4bit`.

## Проект
**Новый проект** (окно 4bit → «Создать проект», или `4bit new "Моя игра"`). Шаблоны:
- `first_person` — двор с моделями Poly Haven (CC0), лампы, игрок от первого лица;
- `empty` — пол-сетка, куб, точка старта.

Папка проекта:
| | |
|---|---|
| `project.json` | название, стартовая сцена, окно, `render.frame_lines` (высота кадра: 360 — «шакальный», 720 — чёткий), `render.look` (`clean` / `lofi`), игрок |
| `scenes/*.json` | сцены: объекты и окружение (небо, солнце/луна, туман, зоны помещений) |
| `assets/models` | модели `.wmdl` (+ текстуры рядом); имя модели — путь без расширения: `props/covered_car` |
| `assets/textures` | текстуры для коробок и материалов; `<имя>_normal.png` — карта нормалей |
| `assets/audio` | звуки `.wav` |
| `src/main.rs` | код игры |
| `AGENTS.md`, `CLAUDE.md`, `.mcp.json` | для ИИ-агентов (см. `docs/AI.md`) |

## Окно 4bit
- **Слева** — сцены, модели, текстуры, звуки проекта; поиск и «Мне повезёт!».
- **В центре** — просмотр: модель (вращать мышью, колесо — ближе, скелет поверх), текстура, звук, состав сцены.
- **Модель** — анимации: выбрать клип, пауза, перемотка по кадрам, скорость; переименовать, цикл, кадров в
  секунду, вырезать кусок в новый клип, дублировать, удалить; **клипы из другой модели** (кости сопоставляются по
  именам — например анимации GMod-скелета на другую GMod-модель); «Сохранить модель» (рядом остаётся `.wmdl.bak`).
- **Импорт** — `.glb` / `.gltf` (Blender, Sketchfab, Poly Haven, Mixamo через Blender: меши, скелет, веса, анимации,
  текстуры) и `.mdl` (Source / GMod). Можно перетащить файл в окно.
- **Мастерская** — ссылка на предмет Garry's Mod → скачать → выбрать модели и звуки → в проект. Автор записывается в
  `assets/models/WORKSHOP.md`. Такие ассеты остаются на условиях их авторов (обычно — не для продажи).
- **Сборка** — релиз для этого компьютера в `Builds/` (на Mac — `.app`) и zip; «Проверить проект».
- **Играть** / **Редактор сцены** — собрать и запустить игру.

## Редактор сцены (`--editor`)
Игра со своим настоящим рендером, панели поверх.
- ПКМ + WASD/QE — летать (Shift быстрее), колесо — вперёд, F — к выбранному.
- Клик — выбрать; стрелки гизмо — двигать по оси, жёлтый квадрат — по полу; Ctrl — шаг 0,25 м.
- «+ модель / лампа / коробка / старт»; Ctrl+D — копия, Del — удалить, Ctrl+Z — отменить, Ctrl+S — сохранить.
- Ничего не выбрано — инспектор показывает **окружение**: небо, солнце/луна и его направление, туман, свет в
  помещениях, высота этажа (лампы не светят сквозь перекрытия).
- ▶ Играть / Пауза / Шаг / Стоп, скорость времени; виды: коллайдеры, лампы, свет камеры.

## Код игры
```rust
use fourbit::{glam::Vec3, Engine, Game, Key};
struct MyGame;
impl Game for MyGame {
    fn init(&mut self, e: &mut Engine) { e.world.lamp(Vec3::new(0.0, 3.0, 2.0), Vec3::ONE, 1.5, 8.0); }
    fn update(&mut self, e: &mut Engine, _dt: f32) { if e.input.pressed(Key::KeyE) { e.say("привет", 2.0); } }
}
fn main() { fourbit::run(MyGame); }
```
Полный список: `AGENTS.md` проекта (он же — шпаргалка для людей).

## Координаты
Метры, ось Y вверх, +Z вперёд, +X вправо, левая система — как в Unity: числа переносятся один в один.
